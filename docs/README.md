# Docs

| File | Use |
|------|-----|
| `WORK_WORK_LOOP_DRAFT_V1.txt` | Machine-parseable kernel. Load this before a phase. |
| `WORK_WORK_LOOP_v1.md` | Human spec of the same kernel. |
| `START_ANY_TASK.txt` | Card that starts a job. Fill `[IDEA]`. Leave `[SPINE] BIBLE`. |
| `grok-start-prompt.md` | Five-stage prompt for one Grok phase. |

The phase CLI that reads this kernel is `wwl_phase` at the repository root.
